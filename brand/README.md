# Integration icon

Original generic flame artwork created for this project, licensed under the
repository's [MIT license](../LICENSE). It contains no NBE, StokerCloud or
Home Assistant brand artwork and does not imply endorsement.

`icon.svg` is the editable source. `icon.png` (256 × 256) and `icon@2x.png`
(512 × 512) are transparent PNG exports for Home Assistant's local integration
brand images. The same colors work on light and dark backgrounds.
